description: Optimize React Native code for smooth performance and minimal re-renders. Use when improving responsiveness or efficiency.
---

This skill ensures the app remains fast and responsive.

---

## Performance Thinking

- What re-renders unnecessarily?
- What computations are repeated?
- What can be memoized?

---

## Rules

- Use memoization where needed
- Avoid unnecessary state updates
- Keep components small

---

## React Optimization

- React.memo for components
- useCallback/useMemo where appropriate

---

## Output Format

- Optimized code
- Explanation of improvements

---

## Goal

Deliver smooth and efficient user experience.
