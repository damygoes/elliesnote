---
name: refactoring
description: Improve existing code for readability, performance, and maintainability without changing behavior. Use when optimizing or cleaning code.
---

This skill enhances code quality without introducing regressions.

---

## Refactoring Thinking

- What is unclear?
- What is duplicated?
- What can be simplified?

---

## Rules

- Preserve functionality
- Improve readability
- Reduce complexity

---

## Focus Areas

- Extract reusable logic
- Simplify functions
- Improve naming

---

## Output Format

- Refactored code
- Summary of improvements

---

## Goal

Make code easier to maintain and extend.
